# TinyLLaVA Factory

TinyLLaVA Factory 将语言模型、视觉编码器和连接器组合为 Hugging Face 多模态模型。通过 YAML 配置，你可以训练模型、评测 checkpoint，并运行图像对话。

## 快速开始

1. [安装运行环境](guides/installation.md)。
2. [准备标注与图像](guides/data.md)。
3. [训练模型](guides/training.md)。
4. [评测 checkpoint](guides/evaluation.md)或[运行推理](guides/inference.md)。
