# TinyLLaVA Factory

TinyLLaVA Factory combines a language model, a vision encoder, and a connector
into a Hugging Face multimodal model. Use YAML configurations to train models,
evaluate checkpoints, and run image-based conversations.

## Get started

1. [Install the runtime](guides/installation.md).
2. [Prepare annotations and images](guides/data.md).
3. [Train a model](guides/training.md).
4. [Evaluate a checkpoint](guides/evaluation.md) or [run inference](guides/inference.md).
